## Photo card capped further + stale-screenshot gotcha

User pasted a screenshot showing the photo still huge after the 300px change. The
served CSS actually contained `.max-w-\[300px\] { max-width: 300px; }` correctly — it
was a stale browser tab / preview cache. Reduced to `max-w-[220px]` and column
`[0.62fr,1.4fr]` -> `[0.5fr,1.5fr]`. Rule confirmed compiled in the global CSS chunk
when fetched fresh. Lesson: when a size change looks unchanged, verify the rule in
the served CSS before changing numbers — it's almost always stale client state.
